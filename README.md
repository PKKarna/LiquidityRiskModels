# Liquidity Risk Models

A production-grade framework for regulatory liquidity risk reporting and stress testing.

## Features
- LCR/NSFR/FR 2052a calculations
- SEC EDGAR API integration for real 10-K data
- Stress testing dashboards (Plotly/Shiny)
- CI/CD pipeline with pytest

## Quick Start
```bash
git clone https://github.com/PKKarna/LiquidityRiskModels.git
cd LiquidityRiskModels
